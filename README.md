# ClinAI — AI Disease Predictor

ClinAI is an AI-powered clinical decision-support web application designed to assist healthcare professionals with disease prediction and patient assessment.

## 🚀 Features

* User authentication and registration
* Disease prediction/assessment
* Clinical assessment dashboard
* Prediction history
* Reports
* Admin functionality
* MySQL database integration
* Responsive web interface

## 🛠️ Technologies

* PHP
* MySQL
* JavaScript
* HTML5
* CSS3
* Git & GitHub
